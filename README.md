#  Shop-Zone

A modern and responsive E-Commerce web application built using React and Vite.  
Shop-Zone provides a smooth shopping experience with product browsing, cart management, category filtering, and responsive UI design.

---

##  Live Demo

https://vercel.com/kchakritha143s-projects/shop-zone/5Bo2ozqW6EuwRt63ifkKC5fEhdyX
---

##  Features

-  Modern Home Page
-  Product Listing Section
-  Search & Category Filtering
-  Add to Cart Functionality
-  Increase / Decrease Product Quantity
-  Cart Total Calculation
-  Fully Responsive Design
-  Fast Performance using Vite
-  Clean and Professional UI

---

Installation & Setup
1️. Clone the Repository
git clone https://github.com/KChakritha143/Shop-Zone.git
2️. Navigate to Project Folder
cd Shop-Zone
3️. Install Dependencies
npm install
4️. Start Development Server
npm run dev
